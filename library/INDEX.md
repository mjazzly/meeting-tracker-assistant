## Limits, entry by entry

- **Conversation Brief Assistant:** Declines, one line each at the top, then delivers the rest: inventing or sharpening a quote; attributing a statement the transcript does not show; keeping a personal name (keeps the role label). Leaves out personal matters about an identifiable person. Asks for any missing required input. One transcript per run. Where: The exemplar pack and the tested v1.4 set, both kept on the owner's machine.
- **Column Mapper:** Never sees your files and never fills a gap. Fewer than ten files: open them instead. Files with different information, not just different headers, are a data model question. Mixed date formats always need your decision. Headers in more than one language untested. Over 200 distinct headers goes in two halves. Where: 01-column-mapper.md.
- **Process Mapper:** Records what was done, not what should be done. Needs at least three recent cases. Refuses to score or shortlist anything. Rare exceptions appear only if a case hit one. Not for cases that cannot be described without personal details. Where: 02-process-mapper.md.
- **Fit Check:** Works from the description, so a vague template gives a vague split. Never recommends a tool the requester does not have. Never promises the task can run unattended. A step with no confirmed data route is marked blocked and treated as JUDGEMENT. Not for one-off tasks. Where: 03-fit-check.md.
- **Pattern Log:** A log, not a ticket queue. Never attaches a name. Its reading of 'what it really was' is a first guess, so the correction step is mandatory. The threshold is a number the owner set in the knowledge file. One action per memo. Where: 04-pattern-log.md.
- **Runbook Writer:** With chat only, the person is the API: every FETCH is their time. It makes the CHAT steps consistent and checkable; it does not shorten the process. Steps that select people are never CHAT. Unsigned maps are refused. Writes the runbook, does not run it. Where: 05-runbook.md.
- **Right-Size:** Hands untested prompts the check instead of a recommendation. Not for general 'which model is best' questions. Knows nothing about any platform's pricing or limits and says nothing about them. Where: 06-right-size.md.
- **Meeting Tracker Assistant:** Synthetic transcripts and a synthetic contacts table; one folder; no scheduling; no email; no external system connected; append and status change only, never a rewrite; stops at four gates Where: this folder: skill/SKILL.md, server.mjs, eval/EXEMPLAR.md.
- **Prompt Drill Coach:** Grades the person's sheet; never writes the sheet for them; a coach for the owner's own practice; would go through five cases before anyone else used it Where: The custom GPT 'Prompt Drill Coach' in the owner's ChatGPT account, saved to himself; the same block runs as the prompt-drill skill in Claude.

Synthetic data only throughout. Nothing here is described as deployed; a tested-on line says only what was observed and names any miss.
